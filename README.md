## 🏗️ Architecture du Site

Stack utilisée :

- React + TypeScript
- Vite (build optimisé)
- Déploiement statique via GitHub Pages

Choix architectural volontaire :

- Aucun backend
- Aucune base de données

Objectif : démontrer une logique d’architecture simple, maîtrisée et cohérente.

---

## 🔐 Threat Model

### Surface d’attaque

- Assets JavaScript générés
- Hébergement GitHub Pages
- Dépendances npm

### Risques identifiés

- Supply chain (compromission dépendances)
- Mauvaise configuration des headers HTTP
- Compromission du compte GitHub

### Risques exclus

- Injection SQL
- Exfiltration de données sensibles
- Session hijacking

Criticité globale : faible (site statique sans données sensibles).

---

## 🛡️ Hardening Envisagé

- Mise en place d’une Content Security Policy (CSP)
- Configuration stricte des headers de sécurité
- Audit régulier des dépendances (`npm audit`)
- Pipeline CI/CD pour validation automatique
- Monitoring d’intégrité du déploiement
